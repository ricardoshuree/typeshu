TypeShuDown

Editor Markdown WYSIWYM desktop — clone turbinado do Typora.

## Stack

* Electron + Vite + React + TypeScript
* Milkdown (motor de edição WYSIWYM)
* EditorAdapter (desacoplado para troca futura de motor)
* agora sim, mais uma linha

## Desenvolvimento

```bash
# Instalar dependências
npm install

# Rodar em modo dev
npm run dev

# Build para distribuição
npm run package
```

## MCP Local

```bash
# Verificar ambiente
python start.py --check

# Monitor em janela separada
python monitor_mcp.py --terminal

```
