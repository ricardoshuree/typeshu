# Changelog

## [0.1.0] - 2026-09-24

### Primeiro release público

- Editor Markdown WYSIWYM baseado em Milkdown
- Suporte a sintaxe GFM (GitHub Flavored Markdown)
- Renderização de fórmulas matemáticas via KaTeX
- Renderização de diagramas via Mermaid
- Highlight de código via Prism
- Suporte a emojis
- Histórico de undo/redo
- Instalador Windows (NSIS) e portable
- macOS DMG
- Auto-update via GitHub Releases
